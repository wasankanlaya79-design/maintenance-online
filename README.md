# ระบบแจ้งซ่อมออนไลน์

ระบบแจ้งซ่อมออนไลน์สำหรับใช้งานบน Vercel โดยเชื่อม Supabase เป็นฐานข้อมูลกลาง

## ฟังก์ชัน
- สร้างใบแจ้งซ่อมและเลขงานอัตโนมัติ
- ใช้งานได้ทั้งมือถือและคอมพิวเตอร์
- Dashboard สรุปงาน
- ช่างรับงานและอัปเดตสถานะ
- บันทึกสาเหตุและวิธีแก้ไข
- ค้นหา/กรองงาน
- Export CSV

## Deploy
Import repository นี้เข้า Vercel ได้โดยตรง ไม่ต้องตั้ง Build Command
